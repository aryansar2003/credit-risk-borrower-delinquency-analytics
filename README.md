# Credit Risk & Borrower Delinquency Analytics

## Business Problem

The lending company wants to understand which borrower characteristics and past payment behaviors are associated with serious delinquency.

The goal of this analysis is to:
- Measure the overall serious delinquency rate.
- Understand delinquency patterns across different age groups.
- Analyze how previous late payments relate to serious delinquency.
- Identify borrower segments with higher observed delinquency rates.
- Present the findings using Python, SQL, and Power BI.

## Project Overview

This project analyzes 149,997 borrower records to understand patterns associated with serious delinquency.

The project follows an end-to-end data analytics workflow:

**Raw Data → Data Cleaning → Exploratory Analysis → SQL Analysis → Power BI Dashboard → Business Insights**

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- MySQL
- Power BI

## Key Findings

- The overall serious delinquency rate was approximately **6.7%**.
- Younger borrowers had higher observed delinquency rates than older age groups.
- Serious delinquency rates generally increased as the number of previous late payments increased.
- Borrowers with **3+ previous 90-day late payments** had the highest observed delinquency rate among the analyzed late-payment groups.
